# Using GuildQuality Respond to Reviews

Write thoughtful replies to customer reviews in ChatGPT or Claude. Connect your GuildQuality account to find reviews and publish approved replies, or start with a review you paste or upload for a draft.

## Install the skill

**[Download Respond to Reviews (beta)](https://github.com/guildquality/guildquality-skills/releases/download/v0.3.0-beta.1/gq-respond-to-reviews.zip)**

Install the complete `gq-respond-to-reviews.zip` using your app's Skills screen. In ChatGPT, choose **Add → Upload from your computer**. In Claude, choose **Customize → Skills → Add → Upload skill** and enable it.

Start a new chat and select the skill, or ask to use **GuildQuality Respond to Reviews**. Keep customer files and saved connections in a separate private folder.

## Connect to find and answer GuildQuality reviews

Use the account connection from [Using GuildQuality Skills](USAGE.md#2-add-your-guildquality-data). An existing saved connection can serve both Analyze Feedback and Respond to Reviews in the same environment. Never paste an API token into chat or upload it.

Ask the assistant to find a review or show reviews that need replies. Before publishing, it shows the review, the current response if any, and the exact proposed reply. Review these details and approve the specific change. Asking for a draft or editing its wording does not publish it.

You can replace an existing reply or ask to remove it. The assistant confirms the change and checks the saved result. If a result is uncertain, it checks the current state before proposing another action.

Connection options depend on your AI app and workspace settings. If your chat cannot connect, copy the draft into GuildQuality to publish it yourself. A reply drafted for Google or another site must be posted through that site's own tools.

## Start with a draft

Paste a review or upload an approved export and describe what you want. For example:

> Help me reply to this unhappy customer. Keep it warm and brief.

You can also ask for a shorter reply, a different tone or another language. Share any confirmed facts you want included, such as a completed service visit or an approved contact route. You do not need an API token to draft a reply.

For several reviews, ask:

> Which reviews should we answer first? Draft replies for the ones we haven't answered.

A missing public reply does not tell the assistant whether your team has helped the customer privately. Include that context when it matters.
