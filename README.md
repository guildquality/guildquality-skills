# GuildQuality Skills

Use your own GuildQuality feedback with your AI assistant. Upload an approved GuildQuality export to analyze its records without an API key, or connect your account to read fresh feedback. Compare months and locations, check scores, and find common themes in comments.

**Current release: 0.2.8-beta.4.** This beta includes **Analyze Feedback**.

**[Download GuildQuality Skills (beta)](https://github.com/guildquality/guildquality-skills/releases/download/v0.2.8-beta.4/gq-analyze-feedback.zip)**

Read [Using GuildQuality Skills](USAGE.md) to install the skill, connect your account, and make reports you can check. Then try the [example questions](EXAMPLES.md).

## What to install

Download **`gq-analyze-feedback.zip`** using the link above and install it using your app's skill setup. Keep the whole skill folder together. It holds the instructions, reference notes, license, and Python tools the assistant needs. Once installed, select it in a normal chat or project. Keep your exports and reports in a separate private folder. The beta reads feedback and writes reports. It does not change your account or send messages.

The other files in this repository help you set up and use the skill:

- `USAGE.md`: the setup and reporting guide.
- `EXAMPLES.md`: questions to try. These guides are for reading, not installation.
- `skills/gq-analyze-feedback/`: the same skill files, unpacked so you can browse them.
